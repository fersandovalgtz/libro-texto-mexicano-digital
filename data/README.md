# Datos

Este directorio no es un depósito de PDF ni imágenes fuente.

- `samples/`: únicamente muestras cuya inclusión sea procedente y necesaria para pruebas reproducibles.
- `derived/`: datos derivados publicables del proyecto.

Los archivos originales de trabajo deberán mantenerse fuera de Git cuando su tamaño o condición jurídica lo aconsejen.
