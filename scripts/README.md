# Scripts

Aquí se incorporarán las rutinas reproducibles del piloto:

1. inventario de fuentes;
2. recuperación de metadatos;
3. extracción/OCR;
4. normalización;
5. segmentación;
6. validación;
7. generación de datos derivados.

Cada script deberá poder ejecutarse sin depender de rutas personales y deberá registrar versiones y procedencia.
