# Roadmap

## Fase 0 — constitución del proyecto

- Definir identidad, alcance y unidad de análisis.
- Registrar fuentes y restricciones jurídicas.
- Diseñar esquema mínimo de metadatos.
- Seleccionar corpus piloto.

## Fase 1 — piloto 0.1

- Inventariar libros seleccionados.
- Recuperar metadatos de procedencia.
- Probar OCR o extracción de texto.
- Segmentar libro → página → fragmento → actividad/imagen/concepto.
- Validar calidad sobre una muestra humana.
- Generar primer dataset derivado.

## Fase 2 — prueba historiográfica

- Formular tres preguntas longitudinales.
- Construir una comparación reproducible.
- Evaluar si los resultados justifican escalar.

## Fase 3 — escalamiento controlado

Sólo si el piloto supera los criterios de acceso, calidad, originalidad, reutilización, publicabilidad y costo:

- ampliar periodos y grados;
- automatizar ingestión;
- establecer API o buscador;
- preparar release versionado;
- archivar release en Zenodo u otro repositorio apropiado;
- asignar DOI y formalizar citación.
