# Plan inmediato de trabajo

## I-01 — Inventario y continuidad

Localizar libros de Ciencias Naturales en las generaciones 1972, 1988, 1993 y 2014; registrar grado, título, URL, estado de navegación y calidad técnica. Elegir el grado con mejor continuidad.

## I-02 — Auditoría jurídica específica

Determinar, con documentación institucional o consulta formal si es necesario, qué productos derivados pueden publicarse: OCR, fragmentos, miniaturas, anotaciones y estadísticas.

## I-03 — Primer pipeline reproducible

Una vez fijados cuatro libros comparables, obtener una muestra local, extraer texto por página, medir calidad y generar el primer dataset derivado sin publicar materiales fuente.
