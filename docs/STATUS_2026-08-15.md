- SEMB 0.1 (MiniLM multilingüe): **FAILED PRE-CORPUS** por colapso geométrico de prototipos y baja discriminación sintética. Nunca se ejecutó sobre LTMD.
- SEMB 0.2: arquitectura E5 multilingüe, revisión pinneada, anclas cortas, desarrollo/validación sintética separados.
- configuración de desarrollo congelada antes de VALIDATION_B02: `max_anchor`, action gate 0.00 y parámetros multilabel/incertidumbre preregistrados.

## Estado científico

El proyecto ya superó la etapa de infraestructura: existe un pipeline completo y reproducible `CONALITEG → OCR → estructura de página → fragmento → RULEA → SEMB validado → acuerdo A/B → comparación longitudinal`, sin publicación de texto fuente extenso y sin revisión humana.

El siguiente frente es **interpretación historiográfica computacional**: leer los resultados robustos y method-sensitive, contrastarlos con contexto curricular y formular el primer argumento/artículo del piloto. Cualquier selección de “hallazgos principales” a partir de ahora se rotulará como exploratoria si no quedó fijada previamente en `HISTORICAL_COMPARISON_SPEC_0_1.md`.
